اختر منصة متجر جاهزة
  • بالخليج: سلة أو زد (دفع كي نت، توصيل، واتساب، فواتير). عالمياً: Shopify (أوسع تطبيقات، بس الدفع المحلي يحتاج بوابة إضافية).
  • سجّل، اختر قالب، ضف الشعار والألوان. ساعة وحدة ويطلع لك متجر شغّال.
2

المنتجات والمخزون
  • لكل منتج: صور، وصف، المقاسات/الألوان كـ variants، السعر، التكلفة، والكمية.
  • فعّل «تتبع المخزون» وحدّد «تنبيه عند الكمية» — المنصة تخفي المنتج لما يخلص وتنبهك.
  • ضف التكلفة لكل منتج من البداية. بدونها ما تقدر تعرف الربح الحقيقي بعدين.
3

الدفع والتوصيل
  • اربط بوابة الدفع (كي نت / تاب / ماي فاتورة) من إعدادات المنصة — عادة بدون كود.
  • التوصيل: شركات التوصيل المدمجة أو مندوبك مع رسوم ثابتة. رسومك الحالية: ٢ د.ك.
  • فعّل رسائل واتساب للطلب (معظم المنصات الخليجية فيها): تأكيد، تجهيز، مع المندوب، وصل.
4

الخصومات والسلة المتروكة
  • أكواد الخصم: نسبة، تاريخ انتهاء، حد استخدام. اعمل كود BACK10 لمرة وحدة.
  • فعّل «استرجاع السلة المتروكة» وحدّد الرسالة والوقت (ساعة بعد الترك).
5

التقارير
  • لوحة المنصة تعطيك المبيعات والطلبات والأكثر مبيعاً. اللي ما تعطيك: الرواتب، المصاريف، والربح الحقيقي — هذي بالمستوى ٢ و٣.
المستوى ١ كافي لمتجر يبدأ. تنتقل للمستوى ٢ لما تحتاج تقرير صباحي أو ربط مع محاسبة.
1

المنصة ← Make
  • Make.com (أو Zapier): اربط حساب المتجر. كل «طلب جديد» و«تغيّر مخزون» يصير حدث تقدر تبني عليه.
  • Shopify وWooCommerce مدعومين مباشرة. سلة وزد عبر Webhooks من إعدادات المنصة ← «Webhook» وحدة بـ Make.
2

تنبيه المخزون + طلب المورّد
  • سيناريو: مخزون منتج < ٥ ← واتساب لك ← صف جديد بشيت «طلبات الشراء» ← إيميل للمورّد بالكمية.
3

المحاسبة والرواتب
  • كل طلب مدفوع ← قيد بـ Zoho Books / QuickBooks (إيراد، رسوم، صافي) — من شرح المحاسبة.
  • شيت «الموظفين»: الراتب + عمولة ٪ على المبيعات اللي باسم كل موظف (المنصة تسجّل البائع على الطلب).
  • شيت «المصاريف»: الإيجار، الإعلانات، التوصيل — عشان الربح الحقيقي = المبيعات − التكلفة − المصاريف.
4

الولاء والتقييمات والإرجاع
  • نقاط: عند «تم التوصيل» ← +١ نقطة لكل دينار بشيت العملاء ← واتساب بالرصيد.
  • تقييم: بعد التوصيل بـ ٣ ساعات ← «شلون كانت تجربتك؟» ← راضي: رابط قوقل · مو راضي: صف بشيت «شكاوى» + تنبيه لك.
  • إرجاع: نموذج Google Form من صفحة الطلب ← صف بشيت ← زر موافقة يرسل واتساب للعميل.
5

تقرير الساعة ٨

البنية
  • الموقع (للعميل): GitHub Pages — كتالوج، سلة، دفع، صفحة تتبع /t/{order}.
  • اللوحة (لك): صفحة محمية بتسجيل دخول Firebase — منتجات، طلبات، مخزون، موظفين، تقارير.
  • Firestore: products (sku, name, variants, price, cost, stock, reorderAt, supplier, branch) · orders (items, total, status, stage, driver, phone) · ledger · staff · purchase_orders · codes · customers (points).

الدوال

Firebase Functions v2، Node 20. خمس دوال تغطي السلسلة كاملة — الدفع، المخزون والمورّد، التتبع، السلة المتروكة، والتقرير:

// functions/store.js — orders, stock, low-stock alert, PO, tracking, abandoned cart, daily report
const { onRequest } = require("firebase-functions/v2/https");
const { onDocumentUpdated } = require("firebase-functions/v2/firestore");
const { onSchedule } = require("firebase-functions/v2/scheduler");
const admin = require("firebase-admin");
if (!admin.apps.length) admin.initializeApp();
const db = admin.firestore();
// sendWhatsApp(to, text) → same sendText() as the WhatsApp guide; sendEmail() → Resend/SendGrid

// 1) Payment webhook (Tap / UPayments / MyFatoorah) → confirm order, decrement stock, post ledger entry
exports.payWebhook = onRequest({ region: "us-central1" }, async (req, res) => {
  const c = req.body;                                   // verify signature per gateway docs
  if (c.status !== "CAPTURED" || !c.metadata?.order) return res.sendStatus(200);
  const ref = db.collection("orders").doc(c.metadata.order);
  await db.runTransaction(async (tx) => {
    const o = (await tx.get(ref)).data();
    if (o.status === "paid") return;                   // idempotent (gateways retry)
    for (const it of o.items) {
      const p = db.collection("products").doc(it.sku);
      const stock = (await tx.get(p)).data().stock - it.qty;
      tx.update(p, { stock });
    }
    tx.update(ref, { status: "paid", paidAt: new Date(), stage: "preparing" });
    tx.set(db.collection("ledger").doc(), { type: "sale", order: ref.id, gross: o.total, fee: +(o.total * 0.01).toFixed(3), net: +(o.total * 0.99).toFixed(3), at: new Date() });
  });
  // sendWhatsApp(o.phone, `تم استلام طلبك #${o.number} ✅ تابعه: https://YOUR-SITE/t/${ref.id}`)
  res.sendStatus(200);
});

// 2) Low stock → WhatsApp alert + auto purchase order to the supplier
exports.onStockChange = onDocumentUpdated({ document: "products/{sku}", region: "us-central1" }, async (ev) => {
  const b = ev.data.before.data(), a = ev.data.after.data();
  if (a.stock < a.reorderAt && b.stock >= a.reorderAt) {
    // sendWhatsApp(OWNER, `⚠️ ${a.name} — باقي ${a.stock} قطع. أعد الطلب`)
    const po = await db.collection("purchase_orders").add({ sku: ev.params.sku, name: a.name, qty: a.reorderQty, supplier: a.supplier, cost: a.cost, status: "draft", at: new Date() });
    // sendEmail(a.supplierEmail, `طلب شراء #${po.id}: ${a.name} × ${a.reorderQty}`)
  }
});

// 3) Driver updates stage → customer sees it live on /t/{order}
exports.setStage = onRequest({ region: "us-central1" }, async (req, res) => {
  const { order, stage, driver } = req.body;           // preparing | with_driver | delivered
  await db.collection("orders").doc(order).update({ stage, driver, [`stageAt.${stage}`]: new Date() });
  // if (stage === "delivered") sendWhatsApp(phone, "وصل طلبك؟ شلون كانت تجربتك؟ 1 راضي · 2 مو راضي")  + loyalty points
  res.sendStatus(200);
});

// 4) Abandoned carts: pending orders older than 60 min → WhatsApp with a one-time code
exports.abandonedCarts = onSchedule({ schedule: "every 15 minutes", region: "us-central1", timeZone: "Asia/Kuwait" }, async () => {
  const cutoff = new Date(Date.now() - 60 * 60e3);
  const snap = await db.collection("orders").where("status", "==", "pending").where("created", "<", cutoff).where("nudged", "==", false).get();
  for (const d of snap.docs) {
    const code = "BACK10-" + d.id.slice(0, 4).toUpperCase();
    await db.collection("codes").doc(code).set({ pct: 10, once: true, expires: new Date(Date.now() + 24 * 3600e3), order: d.id });
    // sendWhatsApp(d.data().phone, `نسيت شي؟ 👀 خذ ١٠٪ بكود ${code} — صالح ٢٤ ساعة`)
    await d.ref.update({ nudged: true });
  }
});

// 5) 8 AM owner report
exports.dailyReport = onSchedule({ schedule: "0 8 * * *", region: "us-central1", timeZone: "Asia/Kuwait" }, async () => {
  const since = new Date(); since.setDate(since.getDate() - 1); since.setHours(0, 0, 0, 0);
  const orders = await db.collection("orders").where("paidAt", ">=", since).get();
  const total = orders.docs.reduce((s, d) => s + d.data().total, 0);
  const low = await db.collection("products").where("stock", "<", 5).get();
  const carts = await db.collection("orders").where("status", "==", "pending").where("nudged", "==", true).where("created", ">=", since).get();
  const msg = `صباح الخير ☀️ تقرير أمس:\n🛍 ${orders.size} طلب · ${total.toFixed(3)} د.ك\n⚠️ ${low.size} منتجات على وشك النفاد\n🛒 ${carts.size} سلات متروكة — أرسلنا لهم كود`;
  // sendWhatsApp(OWNER, msg)
});

الدفع والفواتير
  • السلة تنشئ orders/{id} بحالة pending ثم تطلب رابط دفع من البوابة مع metadata.order = id.
  • payWebhook يأكّد الطلب، ينقص المخزون داخل transaction (عشان ما ينباع منتج مرتين)، ويسجّل القيد.
  • الفاتورة PDF: نفس طريقة شرح المحاسبة — تولّدها بالدالة وترسلها واتساب.
4

التوصيل والتتبع
  • صفحة للمندوب (نفس اللوحة بصلاحية driver): يختار الطلب ← «استلمت» ← «وصل». كل ضغطة تستدعي setStage.
  • صفحة التتبع للعميل تقرأ orders/{id} مباشرة بـ onSnapshot — تتحدث لحظياً بدون تحديث.
  • تبي خريطة حيّة؟ المندوب يرسل موقعه كل ٣٠ ثانية من صفحته ← الصفحة تعرضه على خريطة. ابدأ بدونها.
5

الموظفين والرواتب والمصاريف
  • staff/{id}: الراتب، نسبة العمولة، نوع (مبيعات/مندوب/مخزن). كل طلب يحمل soldBy وdriver.
  • كشف الرواتب آخر الشهر = راتب + Σ عمولة الطلبات المدفوعة + Σ التوصيلات. دالة مجدولة تولّده كـ PDF.
  • المصاريف تنسجل بـ ledger بنوع expense. الربح الحقيقي = Σ net − Σ cost − Σ expense.
6

الفروع والإرجاع والولاء
  • المخزون لكل فرع: products/{sku}/stock_by_branch. زر «نقل» يخصم من فرع ويضيف لفرع داخل transaction.
  • الإرجاع: زر بصفحة التتبع ← returns/{id} ← موافقة من اللوحة ← استرداد عبر البوابة + رجوع المخزون.
  • الولاء: عند delivered ← customers/{phone}.points += floor(total). ١٠٠ نقطة = كود خصم ٥ د.ك يتولد بروحه.
ابنِ بالترتيب: الكتالوج والدفع ← المخزون ← التتبع ← التقرير. الباقي إضافات على نفس البيانات.
