Make Instagram answer your DMs for you.

Someone comments a keyword on your post, follows you, and gets a DM with your resource — all in under two seconds, with nobody touching the phone. This page walks you through it. Tick each step as you go; your progress is saved on this device.

1

Switch to a Professional account

Instagram only lets Business or Creator accounts use message automation. It's free and reversible.

  • Instagram app → your profile → menu → Settings and privacy → Account type and tools → Switch to professional account.
  • Pick a category. "Business service" or "Software company" both work.
  • Then: Settings → Messages and story replies → Message controls → set "Allow access to messages" to on. Without this, the bot can't send.
2

Create a ManyChat account and connect Instagram
  • Go to manychat.com, sign up, choose Instagram as your channel.
  • Log in with Instagram when asked and allow all requested permissions (messages, comments). If it won't connect, step 1's "Allow access to messages" toggle is usually the reason.
  • The free plan covers comment-to-DM and keyword replies. You only need to pay later for advanced follow checks or large audiences.
3

Build the comment-to-DM automation
  • Automation → New Automation → Instagram → "Send a message when someone comments on a post" (names change a little between ManyChat versions).
  • Choose a specific post (your carousel) — or "any post" if you want one flow for everything.
  • Trigger on specific keywords. Add the keyword in every spelling people will use: AI, ai, Ai, plus Arabic variants like اي and ذكاء.
  • Turn on public reply to the comment and paste this (ManyChat rotates between several if you add more):
Instagram's own rule: the bot can only DM someone who commented, replied to a story, or messaged you first. The comment is the opt-in — that's why the keyword matters.
4

Write the DM: opener, follow gate, reward

Three messages, in order. Copy and paste them into the flow.

Message 1 — the opener (this is your proof)

Message 2 — the follow gate (add a button under it labelled "I'm following")

Message 3 — the reward + next question (attach after the button, add 3 quick-reply buttons)

On the Pro plan you can add a real "Is follower?" condition before message 3. On the free plan the button is an honor system — it still converts most people, because they want the reward.
5

Add a default reply for every new DM

This catches people who DM you directly instead of commenting. Automation → Default Reply (sometimes under "Basic"). Set it to reply once per 24 hours so it doesn't spam a real conversation.

  • Reply 1 → send the same reward flow as step 4.
  • Reply 2 → ask for business name + WhatsApp number, save them to the contact. This is your lead list.
  • Reply 3 → a short thank-you, then stop. You answer by hand.
6

Test it with a second account
  • Set the automation to Active.
  • From another account (a friend's is fine), comment the keyword. You should see the public reply within seconds and a DM right after.
  • Tap the follow button, check message 3 arrives and the link opens.
  • Nothing happened? Check in this order: automation is Active → the post is the right one → keyword spelling → "Allow access to messages" in Instagram.
7

Post, pin, and keep the loop going
  • Pin a comment from yourself on the post with the keyword in it. People copy what they see.
  • Change the keyword per post (AI, AUTO, BOT…). One flow per post keeps the stats clean.
  • Reply by hand to anyone who writes after the bot. Automation opens the conversation; you close it.
  • Check ManyChat's contact list weekly — every person in it opted in. That's your audience for the next launch.

Create a Meta app with Instagram Messaging
  • Your Instagram must be a Professional account (see the no-code route, step 1).
  • developers.facebook.com → Create app → use case "Manage messaging and content on Instagram" (Instagram API with Instagram Login).
  • Add your Instagram account as a tester, generate a user access token with instagram_business_basic, instagram_business_manage_messages and instagram_business_manage_comments. Exchange it for a long-lived token (60 days) and store it as a secret.
  • For your own account you can run in development mode. To message the public you need App Review for the messaging permission — budget a few days and record a screen video of the flow.
2

Deploy a webhook Cloud Function

One HTTPS function handles both the verification handshake (GET) and events (POST). Firebase Functions v2, Node 20. Set the secrets first:

firebase functions:secrets:set IG_TOKEN
firebase functions:secrets:set IG_VERIFY_TOKEN
firebase functions:secrets:set IG_APP_SECRET
// functions/igWebhook.js
const { onRequest } = require("firebase-functions/v2/https");
const { defineSecret } = require("firebase-functions/params");
const crypto = require("crypto");

const IG_TOKEN = defineSecret("IG_TOKEN");
const IG_VERIFY_TOKEN = defineSecret("IG_VERIFY_TOKEN");
const IG_APP_SECRET = defineSecret("IG_APP_SECRET");

const KEYWORDS = ["ai", "اي", "ذكاء"];
const GRAPH = "https://graph.instagram.com/v21.0";

async function ig(path, body, token) {
  const r = await fetch(`${GRAPH}/${path}`, {
    method: "POST",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body: JSON.stringify(body),
  });
  if (!r.ok) throw new Error(`${path} ${r.status} ${await r.text()}`);
  return r.json();
}

exports.igWebhook = onRequest(
  { region: "us-central1", secrets: [IG_TOKEN, IG_VERIFY_TOKEN, IG_APP_SECRET] },
  async (req, res) => {
    // 1) Verification handshake
    if (req.method === "GET") {
      const ok = req.query["hub.mode"] === "subscribe" &&
                 req.query["hub.verify_token"] === IG_VERIFY_TOKEN.value();
      return ok ? res.status(200).send(req.query["hub.challenge"]) : res.sendStatus(403);
    }

    // 2) Signature check
    const sig = req.get("x-hub-signature-256") || "";
    const expected = "sha256=" + crypto
      .createHmac("sha256", IG_APP_SECRET.value())
      .update(req.rawBody).digest("hex");
    if (sig.length !== expected.length ||
        !crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected))) {
      return res.sendStatus(401);
    }
    res.sendStatus(200); // ack fast; Meta retries if you take >20s

    const token = IG_TOKEN.value();
    for (const entry of req.body.entry || []) {
      for (const ch of entry.changes || []) {
        if (ch.field !== "comments") continue;
        const c = ch.value;
        const text = (c.text || "").trim().toLowerCase();
        if (!KEYWORDS.some(k => text.includes(k))) continue;
        if (c.from?.id === entry.id) continue; // ignore my own comments
        try {
          await ig(`${c.id}/replies`, { message: "Check your DMs 📩 شوف الدايركت" }, token);
          await ig(`${entry.id}/messages`,
            { recipient: { comment_id: c.id },
              message: { text: "هلا 👋 هالرد وصلك بأقل من ثانيتين بدون أي تدخل بشري.\nWant the exact setup? Follow me, then reply YES." } },
            token);
        } catch (e) { console.error(e.message); }
      }
    }
  }
);

Export it from index.js, then deploy only this function:

firebase deploy --only functions:igWebhook
3

Subscribe the webhook
  • Meta app dashboard → Instagram → Webhooks → callback URL = your function URL, verify token = the IG_VERIFY_TOKEN you set.
  • Subscribe to comments and messages.
  • Then subscribe your account to the app: POST /<IG_USER_ID>/subscribed_apps?subscribed_fields=comments,messages with your token.
  • Comment the keyword from a test account. Watch firebase functions:log --only igWebhook.
4

Handle replies and store leads in Firestore

Messaging events arrive under entry[].messaging[]. Route on the text and keep a tiny state machine per sender:

for (const m of entry.messaging || []) {
  if (!m.message?.text || m.message.is_echo) continue;
  const sender = m.sender.id;
  const t = m.message.text.trim().toLowerCase();
  const ref = db.collection("ig_leads").doc(sender);
  const snap = await ref.get();
  const state = snap.exists ? snap.data().state : "new";

  if (t === "yes" && state === "new") {
    await ig(`${entry.id}/messages`, { recipient: { id: sender },
      message: { text: `Here you go: ${GUIDE_URL}\nWhat should I automate next? 1 WhatsApp  2 Bookings  3 Reports` } }, token);
    await ref.set({ state: "rewarded", at: new Date() }, { merge: true });
  } else if (["1","2","3"].includes(t)) {
    await ref.set({ interest: t, state: "qualified" }, { merge: true });
    await ig(`${entry.id}/messages`, { recipient: { id: sender },
      message: { text: "Perfect. Send me your business name and WhatsApp number and I'll reach out." } }, token);
  }
}
Rules that bite: you can only message a user within 24 hours of their last message to you; the comment_id recipient works once per comment; and a follow check isn't exposed by the API, so gate on a reply ("YES") instead.
5

Add an AI reply for everything else

Unmatched messages go to a language model with a short system prompt about you and a hard rule to answer in the sender's language and keep it under 3 lines. Store the API key as a secret, cap replies to 1 per message, and always offer a way to reach the human:

const SYSTEM = `You are the DM assistant for ${HANDLE}, an IT manager in Kuwait who builds
AI and automation systems. Answer in the sender's language (Kuwaiti dialect for Arabic,
use "منو" never "مين"). Max 3 short lines. If they want work done, ask for business name
and WhatsApp number. Never invent prices.`;
Start with the keyword flow only. Add the AI fallback once you've read 50 real DMs — then you know what people actually ask.
6

Rotate the token and go live
  • Long-lived tokens expire after 60 days. Add a scheduled function that calls GET /refresh_access_token?grant_type=ig_refresh_token every 30 days and updates the secret.
  • Submit App Review for instagram_business_manage_messages with a screen recording of comment → DM → reply.
  • Switch the app to Live mode. Post the carousel. Pin the keyword comment.
7

Measure
  • Log every event to a Firestore collection: comment → DM sent → YES → interest → contact given.
  • The only numbers that matter: comments per post, % that replied YES, % that left a number. Fix the weakest step first.
