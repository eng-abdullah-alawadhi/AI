مدير ذكي يشغّل محلك… طول اليوم.

ملابس، ساعات، ذهب، إلكترونيات… أي محل عنده مخزون. هني تتعلم تسويه بنفسك بـ Claude، بدون برمجة: يشيك المخزون ويكتب طلب المورد، يرد على الزباين، يكتب الكابشن، يرد على التقييمات، ويدزلك ملخص آخر اليوم.

بدون برمجة٥ خطواتClaude + شيت المخزون

محلك

عبّي هذي والتعليمات تحت تنكتب على محلك.

0 / 0
1

سوّ شيت المخزون

سطر لكل منتج ولون أو مقاس. خل هذي عناوين الأعمدة بـ Excel أو Google Sheets:

  • «حد الطلب» = الرقم اللي إذا وصلته تبدا تقلق (مثلاً ٥).
  • خل شيت ثاني لطلبات اليوم: رقم الطلب، الزبون، المنتج، الكمية، الحالة.
ملابس: المقاس بعمود الموديل. ساعات وإلكترونيات: الموديل أو اللون. ذهب: الوزن والعيار.
2

سوّ Project بـ Claude
  • افتح claude.ai ← Projects ← Create project، وسمّه «مدير» + اسم محلك.
  • بـ Project knowledge ارفع: سياسة التوصيل والإرجاع، أكثر أسئلة الزباين، و٣–٥ كابشنات عجبتك.
  • لا ترفع شيت المخزون هني… بترفق النسخة الجديدة كل صبح.
3

الصق التعليمات

افتح Project instructions والصق هذا. هذا يعطي المدير ٦ شغلات، كل وحدة تبداها بكلمة.

4

يومك ويا المدير

افتح محادثة وحدة كل يوم داخل المشروع، ودز هذي بوقتها:

اقرا دايماً قبل لا ترسل: المدير يكتب، وانت توافق. ولا تخليه يوعد بموعد توصيل ما تقدر عليه.
5

خله يرد على الـ DM بروحه
  • اربط الانستغرام بـ ManyChat ← Automation ← Default reply.
  • ضيف AI step والصق هذي القواعد كتعليماته.
ما يشوف المخزون الحين… فما يقول «متوفر» أبد، يرسل رابط الطلب وإنسان يأكد.

هذا شكله لما يخلص

تجربة ببيانات مثال… وما ينرسل أي شي هني لأي مكان.

اللي ما يقدر عليه الـ Project بروحه

  • يشتغل الساعة ٨ بروحه… انت اللي تفتحه وتدز الكلمة.
  • يشوف المخزون لايف… بس الشيت اللي ترفقه.
  • يستقبل الطلبات والدفع بروحه.
  • يرسل للزبون لما يطلع الطلب… يكتبها، وانت ترسلها.

خلصت؟ الحين محلك عنده مدير ما ينام.

ولو ما تقدر تسويه… إحنا نسويلك اياه: موقع خاص فيكم، بثيم البراند حقكم، يستقبل الطلبات، يحدّث المخزون، ويرد على الزباين… بروحه.
